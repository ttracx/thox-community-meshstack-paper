# Development — THOX Community MeshStack Paper

## Architecture

One evidence source drives everything: `exp/results/summary.json`, generated by `exp/community_lab.py`. `wp/figures.py` and `wp/build_paper.py` consume only that file for lab numbers. `dist/` holds the rendered editions; never edit a file in `dist/` by hand — fix the source and rebuild.

- `exp/community_lab.py` — the Virtual Lab: `plan_pipeline` (first-fit contiguous two-domain planner), `GrantGraph` (attenuable, principal-bound grants with epoch + fingerprint validation and crypto-shredding), `chunk_key` (parent-chained HMAC-SHA256), `Ledger` (hash-chained append-only log with Merkle root + inclusion proofs), churn simulation, MeshCredits example.
- `wp/build_paper.py` — renders the paper HTML in the THOX Research Paper Template v1.0 design from `summary.json`; the PDF is rendered from that HTML with WeasyPrint; the DOCX is a LibreOffice conversion of the shipped HTML.

## Dev environment

Python 3.10+ (lab is stdlib-only). Paper build additionally uses matplotlib (figures) and WeasyPrint (PDF). No services, no network, no credentials.

## Build and test

```bash
python3 exp/community_lab.py > exp/results/summary.json
python3 exp/test_lab.py            # 5 tests, all must pass
python3 wp/figures.py
python3 wp/build_paper.py
```

## Conventions

- Evidence honesty is the repo's core convention: every number carries its class (MEASURED household / CALCULATED / SIMULATED / LAB-MEASURED general host). A simulated result never supports a device claim.
- Commit style: conventional prefixes (`paper:`, `lab:`, `docs:`, `release:`), one topic per commit.
- Branching: work on short-lived branches, merge to `main`; releases are tagged `vX.Y.Z` on `main` with the paper trio attached.
- Any byte change to a released paper edition is a new edition and a new release; never overwrite a release asset silently.

## Known limitations

- The lab is a specification harness: it computes plans, keys, grants, proofs and accounting, and executes no tokens.
- Figures 1–3 labels are small at print size; full-resolution PNGs are in `wp/figures/`.
- No DOI, no Zenodo/arXiv deposit, no website paper page yet — each is a separate founder-gated step.
